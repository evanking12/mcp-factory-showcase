# Architecture Chart Sets

This folder is intentionally split into progressive chart sets so the diagram
surface stays useful without becoming overwhelming.

Start with:

- `CHART-CONVENTIONS.md`
- `01-engineering-overview-4/`

- `01-engineering-overview-4/`
  - Smallest strong set for understanding what the code does.
- `02-architecture-thesis-5/`
  - Adds the truth/compounding layer needed to explain the architecture claim.
- `03-full-thesis-6-cross-dll/`
  - Adds campaign and cross-DLL interweave once that layer is stable enough to explain cleanly.

Use the smallest set that answers the current question.
