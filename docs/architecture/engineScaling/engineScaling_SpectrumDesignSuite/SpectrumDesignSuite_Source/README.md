# Spectrum Design Suite Source

This folder holds the first authored source tranche for the Spectrum Design
Suite.

Current family:

- `transaction_release_settlement_suite`

This tranche includes:

- shared family scaffold
- `easy-01`
- `medium-01`
- `medium-02`
- `hard-01`
- `hard-02`
- observer artifacts
- expected-versus-observed payloads

The goal is not full runtime integration yet. The goal is to author the
enterprise mock system sharply enough that the next review can decide whether
the cases preserve the design contracts or have become too polite or too vague.
